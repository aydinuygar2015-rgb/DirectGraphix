# DirectGraphix
A DirectX 11 mod template for Minecraft 26.3.

## What is this?
DirectGraphix is a work-in-progress DirectX 11 base for Minecraft. **Note:** This is not a complete/playable mod.

## How to use it
1. Extract `src.7z` into a Fabric example mod directory.
2. Make sure you don't misplace any files during extraction.

## Why is it open-source?
I'm releasing it as open-source because I'm stuck on a texture bug and haven't been able to fix it for 5 days.
